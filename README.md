## Why the code you copied stopped working

SHEIN codes aren't one global pool. They're tied to a specific country or region, a specific account status, and almost always a short window. Many of them carry an internal clock that starts the moment you apply them — SHEIN's own explainer pages describe discounts sitting in a "temporarily held for up to 24 hours" state, which means the code you saved last week is often dead by the time you check out.

Add the account condition and it gets worse. A large share of the codes circulating are new-customer codes, meaning they only unlock on an account that has never placed an order. That's why the same code works for one person and fails for the next, and why "create a fresh account" shows up in almost every tip thread. It also means any code list you find is a snapshot, not a permanent answer. Treat it as a lead, verify it in the app, and don't plan a haul around a code you found on a page that doesn't show a date.

## Two different things people mean by "SHEIN coupon code"

The confusion here costs people real money, because the two types don't behave the same way.

**Checkout promo codes.** These go in the promo field on the payment screen, which is how SHEIN's own help documentation describes it: enter your shipping details, pick payment and delivery, then apply the code. You can also combine SHEIN points and any wallet credit at the same step. If a code is going to reduce your order total directly, this is where it happens.

**Search-bar codes.** Type a code into SHEIN's search bar and it doesn't apply a discount to your cart — it opens a curated page or category of already-reduced items. Creators share these constantly, and the numbers attached to them are wild (60% off for new users, category pages at 70% or 90%). What's actually happening is that the code routes you to a promotion page with pre-discounted stock. You then have to complete the purchase within a set window for the pricing to hold.

That distinction matters for cashback, which is the next section. A search-bar code that just surfaces cheaper items doesn't sit in the same category as a checkout promo code, and the two can behave differently when a cashback platform checks your order.
